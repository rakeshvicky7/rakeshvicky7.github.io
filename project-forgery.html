Scientific Image Forgery Detection

Computer vision · Kaggle competition (Recod.ai / LUC) · Python, OpenCV

Finding regions of a published research figure that were copied and pasted from somewhere else in the same figure — and marking exactly which pixels. The method uses no training data, no GPU and no neural network, and runs in about 1.5 seconds per figure on a laptop.

View the repository

1 · The idea behind the project

Research papers prove their claims with pictures — microscope images, western blots, gels. One of the most common forms of misconduct is to take a region of one of those pictures and paste it somewhere else in the same figure, so that a control panel and a treated panel appear to show different samples when they show the same pixels.

This is called copy-move forgery, and specialists currently find it by eye. The task here is to find it automatically: given a figure, decide whether it contains a duplicated region, and if so mark precisely which pixels belong to it.

The property the whole method rests on

A forger can shift the copied patch, rotate it, scale it, brighten it or add noise. What they cannot easily remove is that two places in the picture now contain the same content related by one consistent geometric transform. Every stage of this pipeline looks for exactly that, which is why it needs no examples of forgery to learn from.

That also fixes its limits. It finds duplication within one image. It cannot detect a region pasted in from a different image, a generative edit, or a global recolour — in those cases there is no second copy to match against.

2 · The data, and how it is scored

Understanding the scoring function turned out to matter more than any modelling decision, so it is worth setting out first.

Three sets of images, and a trap between them

The competition supplies a training set of synthetic single-panel copy-move images. The hidden test set is multi-panel published figures — a completely different kind of picture, full of legitimate repetition: repeated axis labels, repeated gene names, bar charts with identical hatching. A method tuned on the training set does not transfer, and that mismatch is the single most important fact about this problem.

Between them sits a supplemental set of 48 figures — the only released data drawn from the same distribution as the test set. Those 48 became the validation set. False positives were measured separately on 60 authentic images.

The metric is not accuracy

Scoring is at the level of pixels and of instances, not of images. Each duplication is one instance, and in the ground truth an instance holds exactly two connected regions — the source and the copy — in a single mask. Predictions are matched to ground-truth instances and scored on pixel overlap, with a penalty for predicting more instances than exist. Correctly answering "authentic" on a clean image scores a full point, and roughly 30% of the test set is authentic.

How a forgery is annotated. One duplication is one instance, and that instance contains both the region that was copied and the place it was pasted — together, in a single mask.

Matching the annotation exactly. Emitting the pair as one mask is what the scoring function expects, and it is how this detector outputs its results.

The cost of getting the format wrong. Emitting the source and the copy as two separate instances doubles the predicted count, and the excess-prediction penalty cuts the score from 0.375 to 0.269 — for detections that were otherwise identical. The output format was worth more than most algorithmic changes.

Clean figures count too. Roughly three in ten test figures contain no forgery, and each correct "authentic" earns full marks. Answering "authentic" to everything scores 0.304 — a baseline any real method has to beat, and it means a false alarm is as expensive as a missed forgery.

Testing it on images with known ground truth

A small utility, forge.py, takes any image and creates a genuine copy-move in it — a patch of a chosen size copied a chosen distance — and prints the shift it applied. Running the detector on the result checks whether it recovers that shift. On a 1024×1024 photograph the clean version produced 2 matches and a verdict of "authentic"; with a 200×200 patch copied 600 pixels across, it produced 235 matches and localised the region correctly.

3 · Preparing the figure and finding candidate matches

The first half of the pipeline looks for pairs of points in the image that describe the same local appearance.

The input. A published figure — several panels, each with its own image, and text labels repeated across them. Somewhere in it, one region appears twice.

Preparation. Colour is discarded, the long side is reduced to 1,800 pixels, and local contrast is equalised so that faint texture inside dark blots becomes visible. Resolution matters: detecting at 1,000 pixels instead of 1,800 drops the score from 0.375 to 0.354, because fine texture is what the matcher has to work with.

Keypoints. SIFT selects up to 8,000 points that stay recognisable when the image is scaled, rotated or brightened — corners and textured spots, never flat background. Each is described by a vector summarising the pattern of brightness changes around it.

Matching the image against itself. Every keypoint is compared with every other keypoint in the same figure. A relaxed form of the standard ratio test allows one point to match several others, because a region may have been pasted more than once. Brute-force comparison is used rather than an approximate index, so the result is exactly reproducible between runs.

Discarding near matches. Any pair closer together than 2% of the image is thrown away. Neighbouring pixels in a texture always resemble each other, and those matches describe nothing but local self-similarity.

4 · From scattered matches to a marked region

Matches alone are not an answer. The metric is measured over pixels, so the region has to be filled in — and legitimate repetition has to be ruled out.

Most matches are accidents. Two round cells look alike; two dark patches look alike. Taken individually, a match is weak evidence.

Truth agrees with itself. If a region was copied and moved, every point inside it moved by the same amount, rotation and scale. RANSAC repeatedly guesses a transform from a few matches and counts how many others agree; the story with the most support survives, and the rest are discarded as coincidence. Near-identity transforms are rejected, since "this pixel matches itself" explains nothing.

Filling the region in. The surviving matches say where but cover only a scatter of points, and the score is measured over pixels. So the entire image is warped by the cluster's transform and compared with itself: pixels that agree closely, and that carry local contrast, are kept. Inverting the transform recovers the source region, and the two together form one mask. This single step is worth +0.17 oF1 — more than any other decision in the pipeline.

Ruling out legitimate repetition. Published figures repeat their own labels — gene names, axis titles, panel letters — and a keypoint matcher finds them instantly. A region is rejected when it sits on white paper and is made of thin strokes. Worth +0.08 oF1, and without it the detector reports honest figures as forged.

The last two decisions

Only the strongest detection is reported, plus any other within 90% of its score, to a maximum of three — because predicting more instances than exist is penalised. And if fewer than twenty matches survive RANSAC anywhere in the figure, the output is authentic. That threshold is the difference between a detector and a detector that is safe to run on clean figures.

Why the first attempt was abandoned

The project began the way most people would start it: a pretrained vision transformer with a segmentation head, trained to paint the forged region. It was dropped, and the reasons are specific rather than vague.

  • It never saw a negative example. Training used forged images only, so the network was never asked to predict "nothing here" — while about 30% of the test set is authentic and each of those is worth a full point.
  • The authentic-or-forged rule was circular. The confidence score was the average probability over pixels already thresholded above 0.45 — a quantity that is high by construction and carries almost no information.
  • The output format was wrong. The metric expects one mask per duplication pair; the model produced a single probability map, which cannot be scored as instances at all.
  • Train and test are different distributions. Training images are synthetic and single-panel; test figures are multi-panel publications. The competition's third-place write-up reports that several strong segmentation architectures all failed to transfer, and that the winning approach used no training at all.
  • The reported numbers were the wrong numbers. Image-level accuracy and F1 on a self-made split, not the pixel-level, instance-matched, authentic-aware competition metric.

Re-scored under the actual metric, that model could not have beaten the trivial baseline. The useful lesson was not that deep learning failed — it was that the metric and the data distribution should have been read first.

6 · What it misses, and what would fix it

Smooth regions produce no keypoints

Uniform gels and blank control panels contain almost no texture, so SIFT finds nothing to match. Ten of the 48 validation figures score zero for this reason alone. The fix is a second detector that works on dense pixel blocks rather than keypoints — block matching or panel-level correlation. A panel-comparison branch exists in the code and is switched off: it adds 0.004 oF1 but roughly doubles the false-positive rate on authentic figures, and this metric punishes that harder than it rewards the gain.

Figures with many duplications

Six of the 48 contain between four and seven duplicated pairs, while the detector reports at most three. Those figures are capped well below half credit no matter how accurate each detection is.

Repeated vector graphics still trigger false alarms

Bar charts with identical hatching across time points are genuinely repeated content, and the text-rejection rule does not catch them. Rejecting flat vector graphics without also rejecting real forgeries on white backgrounds is unsolved here.

The false-positive rate is measured on the wrong images

Zero false positives out of 60 sounds conclusive, but those 60 are synthetic single-panel images, not the multi-panel figures the test set contains. The direct way to measure the real rate is two submissions with different detection thresholds — the difference between the two scores is the true cost of false alarms.

Forty-eight figures is a small tuning set

Roughly six hyper-parameters were chosen on those 48 figures, so 0.375 is optimistic by an unknown margin. Stating that is more useful than quoting the number alone.

Mirrored copies are not handled

The estimated transform covers translation, rotation and scaling, but reflections are never tested. A forger who flips the patch before pasting it defeats the detector entirely.
